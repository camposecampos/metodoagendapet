# Método Agenda PET

Página de vendas estática, responsiva e sem dependências de build.

- Arquivo público: `index.html`.
- Checkout oficial: https://pay.hotmart.com/F107860368K?off=r43qklsp&checkoutMode=10
- Acesso protegido dos compradores: https://metodo-agenda-pet.hotmart.app/acesso-central
- A oferta principal não inclui os complementos opcionais do checkout.
- Nenhum material pago ou dado de clientes está neste repositório.

## Publicação

Workflow em `.github/workflows/pages.yml`, executado a cada push na branch main. Se a criação automática do Pages for negada, selecionar Settings → Pages → Build and deployment → Source → GitHub Actions e executar novamente o workflow.

## Validação

Verificados IDs únicos, âncoras internas e destinos de links. Layout inclui breakpoints para celular e desktop, navegação por teclado e preferência de movimento reduzido. A renderização em navegador não foi verificada nesta execução.
